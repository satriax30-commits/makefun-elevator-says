# makefun-elevator-says

Entry for **What the Elevator Would Say** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
single-line complaint from a talking elevator to `/output/entry.txt`:

> Ding. Floor 22, 3:12 a.m.: Dave, one pizza, zero tip for me. I carried him 22 floors. The stairs got the tip.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
